Linux commands quick reference

Linux commands allow you to interact directly with the operating system. From navigating directories and managing files to checking system status and controlling processes, a small set of commands can cover a lot of day-to-day tasks.

Back to Knowledge Centre Talk to DR Technology

Basic Unix commands

These basic commands cover directory navigation, file creation, copying, moving, and working with permissions. They are often the first tools you will reach for in a terminal session.

  • ls: List directory contents.
  • cd: Change the current directory.
  • pwd: Print the current working directory.
  • mkdir: Create a new directory.
  • touch: Create a new file or update the timestamp of an existing file.
  • rm: Remove files or directories.
  • cp: Copy files or directories.
  • mv: Move or rename files or directories.
  • cat: Concatenate and display the content of files.
  • grep: Search for patterns in files.
  • chmod: Change file permissions.
  • chown: Change file ownership.
  • sudo: Execute a command with superuser privileges.
  • man: Display manual pages for commands.
  • clear: Clear the terminal screen.

Navigation

Navigation commands help you move around the filesystem and work with directories.

  • ls -l: Long listing format.
  • ls -a: List all files including hidden files.
  • ls -t: Sort files by modification time.
  • ls -R: List subdirectories recursively.
  • cd ..: Move to the parent directory.
  • cd -: Move to the previous directory.
  • cd /path/to/directory: Change to a specific directory.
  • rmdir: Remove a directory (if empty).
  • rm -r: Remove a directory and its contents recursively.
  • rm -rf: Forcefully remove a directory and its contents.
  • cp -r: Copy directories recursively.

File operations

These commands help you view, search, compare, and manage files.

  • less file: View file content page by page.
  • head file: Display the beginning of a file.
  • head -n 10 file: Display the first 10 lines of a file.
  • tail file: Display the end of a file.
  • tail -n 10 file: Display the last 10 lines of a file.
  • nano or vi: Text editors for creating or editing files.
  • grep -i: Perform a case-insensitive search.
  • grep -r: Search recursively in directories.
  • find /dir -name "filename*": Search for files with a specific name.
  • diff file1 file2: Compare files line by line.

File permissions and system information

Permissions control who can read, write, or execute files. System information commands help you understand load, memory, and disk usage.

  • chmod 755 filename: Owner gets read, write, execute; group and others get read and execute.
  • chown user:group filename: Change owner and group of a file.
  • chgrp group filename: Change group ownership of a file or directory.
  • setfacl: Set file access control lists.

System information

  • top: Display and update sorted information about system processes.
  • ps: Display information about active processes.
  • ps -ef: Display all processes.
  • df: Display disk space usage.
  • df -h: Display sizes in a human-readable format.
  • du: Display disk usage of files and directories.
  • du -sh *: Display total size of each directory in the current directory.
  • uptime: Display system uptime and load averages.
  • free -m: Display amount of free and used memory in megabytes.

Networking

  • ping host: Send ICMP echo requests to a host.
  • ssh user@host: Connect to a remote host via SSH.
  • scp file.txt user@host:/remote/dir/: Securely copy a file to a remote host.
  • wget URL or curl URL: Download files from the internet.
  • wget -O filename URL: Download file and save with a specific name.

Compression and archiving

  • tar -cvf archive.tar files: Create a new tar archive.
  • tar -xvf archive.tar: Extract files from a tar archive.
  • tar -zcvf archive.tar.gz files: Create a gzip-compressed tar archive.
  • tar -zxvf archive.tar.gz: Extract files from a gzip-compressed tar archive.
  • gzip file / gunzip file.gz: Compress or decompress files using gzip.
  • gzip -9 filename: Compress file using maximum gzip compression.
  • zip archive.zip files / unzip archive.zip: Create or extract zip archives.

Process management

  • kill PID: Terminate a process by ID.
  • kill -9 PID: Forcefully terminate a process by ID.
  • killall name: Terminate all processes matching a given name.

Miscellaneous

  • date: Display or set the system date and time.
  • history: Display the command history.
  • history | grep keyword: Search command history for a specific keyword.

ls options

  • -a: Show all files (including hidden).
  • -R: Recursive listing.
  • -r: Reverse order.
  • -t: Sort by last modified time.
  • -S: Sort by file size.
  • -l: Long listing format.
  • -1: One file per line.
  • -m: Comma-separated output.
  • -Q: Quoted output.

Bash shortcuts

  • Ctrl+C: Stop current command.
  • Ctrl+Z: Suspend current process.
  • Ctrl+A: Go to start of line.
  • Ctrl+E: Go to end of line.
  • Ctrl+U: Cut from start of line to cursor.
  • Ctrl+K: Cut from cursor to end of line.
  • Ctrl+R: Search command history.
  • !!: Repeat last command.
  • !abc: Run last command starting with abc.
  • !abc:p: Print last command starting with abc.
  • !$ or Alt+.: Last argument of previous command.
  • !*: All arguments of previous command.
  • ^abc^123: Run previous command, replacing abc with 123.

Bash commands and variables

Useful Bash commands

  • uname -a: Show system and kernel information.
  • head -n 1 /etc/issue: Show distribution information (where available).
  • mount: Show mounted filesystems.
  • date: Show system date.
  • uptime: Show system uptime.
  • whoami: Show your username.
  • man command: Show manual for a command.

Common environment variables

  • env: Show environment variables.
  • echo $NAME: Output value of $NAME variable.
  • export NAME=value: Set $NAME to a value.
  • $PATH: Executable search path.
  • $HOME: Home directory.
  • $SHELL: Current shell.

Directory operations

  • pwd: Show current directory.
  • mkdir dir: Create directory dir.
  • cd dir: Change directory to dir.
  • cd ..: Go up one directory.
  • ls: List files in current directory.

Nano shortcuts

Files

  • Ctrl+R: Read file into buffer.
  • Ctrl+O: Save file.
  • Ctrl+X: Close file / exit nano.

Cut and paste

  • Alt+A: Start marking text.
  • Ctrl+K: Cut marked text or current line.
  • Ctrl+U: Paste text.

Navigate file

  • Alt+/: Go to end of file.
  • Ctrl+A: Beginning of line.
  • Ctrl+E: End of line.
  • Ctrl+C: Show current line and column.
  • Ctrl+_: Go to line number.

Search file

  • Ctrl+W: Find.
  • Alt+W: Find next.
  • Ctrl+\: Search and replace.

I/O redirection

  • cmd < file: Take input of cmd from file.
  • cmd1 <(cmd2): Output of cmd2 as file-like input to cmd1.
  • cmd > file: Send standard output (stdout) of cmd to file.
  • cmd > /dev/null: Discard stdout of cmd.
  • cmd >> file: Append stdout to file.
  • cmd 2> file: Send error output (stderr) of cmd to file.
  • cmd 1>&2: Send stdout to the same place as stderr.
  • cmd 2>&1: Send stderr to the same place as stdout.
  • cmd &> file: Send all output of cmd to file.

Pipes

  • cmd1 | cmd2: Send stdout of cmd1 to cmd2 as input.
  • cmd1 |& cmd2: Send stderr of cmd1 to cmd2 (in some shells).

Command lists

  • cmd1 ; cmd2: Run cmd1 then cmd2.
  • cmd1 && cmd2: Run cmd2 if cmd1 is successful.
  • cmd1 || cmd2: Run cmd2 if cmd1 is not successful.
  • cmd &: Run cmd in the background.

Watching a command

  • watch -n 5 'ntpq -p': Run ntpq -p every 5 seconds and display output.

File permissions and numbers

Permission numbers are calculated by adding values for read, write, and execute. The first digit is owner permission, second is group, third is everyone.

  • 4: read (r)
  • 2: write (w)
  • 1: execute (x)

Screen shortcuts

  • screen: Start a screen session.
  • screen -r: Resume a screen session.
  • screen -list: Show your current screen sessions.
  • Ctrl+A: Activate commands for screen.
  • Ctrl+A c: Create a new terminal window.
  • Ctrl+A n: Go to the next window.
  • Ctrl+A p: Go to the previous window.
  • Ctrl+A ": Show a list of windows.
  • Ctrl+A A: Rename the current window.
